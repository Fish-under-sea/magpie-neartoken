### 3.2 视频与生图互斥

```
video 模型（5）：sd2.0 | veo-3.1 | minimax-h3 | sd2.5 | omni   各只属 1 个分组
image 模型（20）
重叠：0
```

`sd2.0` / `sd2.5` 是站点的 Seedance 视频模型（分组 `[低价] Seedance`，端点 `openai-video`），不是 Stable Diffusion。

模型 id 为「分组 × 模型」，同一模型进多个分组时对应多行；当前 5 个视频模型各 1 组。

### 3.4 请求体

**A. OpenAI 兼容 chat（现有路径）**

```http
POST https://neartoken.cc/v1/chat/completions
authorization: Bearer <token>
content-type: application/json
x-neartoken-group: #35
```
```json
{"model":"gemini-3.8-flash-tts","messages":[{"role":"user","content":"say hello"}],"max_tokens":32}
```

suno 同形，`x-neartoken-group: #67`。

**B. Gemini 原生 generateContent**

```http
POST https://neartoken.cc/v1beta/models/gemini-3.8-flash-tts:generateContent
authorization: Bearer <token>
content-type: application/json
x-neartoken-group: #35
```
```json
{
  "contents": [{ "parts": [{ "text": "Say: hello from NearToken" }] }],
  "generationConfig": { "responseModalities": ["AUDIO"] }
}
```

### 3.5 返回样例（全部为错误，站点当前无可用上游）

| 模型 | 状态 | 返回 |
| --- | --- | --- |
| TTS ×5（chat 与 gemini 原生均同） | 503 | `{"error":{"message":"No eligible account is currently available for this model.","type":"upstream_error","code":503}}` |
| suno ×5 | 404 | `{"error":{"message":"No available channel for this model on the current token","code":"model_not_found"}}` |
| `gemini-3.5-transcribe` | 400 | `{"error":{"message":"use the native generateContent endpoint with inline audio for this transcription model"}}` |

`transcribe` 的 400 说明 ASR 形态是 `generateContent` + `inline_data`，不是 multipart。

## 五、验收

1. 设置 › 图像：视频行出现 NearToken 的 5 个模型，生图行 20 个，两边无重叠；
2. 语音行出现 11 个（5 TTS + 1 转写 + 5 suno），向量行 3 个；
3. 选中 NearToken 的 TTS 调 `generate_audio` → 返回明确文案而不是原始报错；
4. 插件重载导致供应商掉出后，打开插件页 → `neartoken:relist` 自动恢复，无需手动「加回来」；
5. 老宿主（无 `relist`）上插件功能不受影响。
